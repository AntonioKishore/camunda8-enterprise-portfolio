# Camunda 8 Enterprise Portfolio

Student project repository organised by industry domain. Each project is designed for a team of **three students** and uses the same standard structure:

- `bpmn-models/` — BPMN/DMN models, deployment notes, and workflow documentation.
- `backend-springboot/` — Spring Boot services, workers, REST APIs, and backend tests.
- `frontend-react/` — React UI, client-side validation, and frontend tests.

## Repository conventions
1. Keep each project inside its relevant `Domain-*` folder.
2. Do not commit secrets, API keys, credentials, or real personal/medical/financial data.
3. Add a project README describing the use case, team members, responsibilities, setup steps, and screenshots.
4. Use mock data and mock integrations for demonstrations unless external access is explicitly approved.
5. Commit meaningful changes and include screenshots or a short demo recording in the project documentation.

## Domains
- `Domain-01-Banking/` — Banking & Financial Services
- `Domain-02-Insurance/` — Insurance
- `Domain-03-Telecom/` — Telecommunications
- `Domain-04-Retail-Logistics/` — Retail, E-Commerce & Logistics
- `Domain-05-Healthcare/` — Healthcare & Life Sciences
- `Domain-06-Public-Sector/` — Public Sector, Government & Utilities
- `Domain-07-Enterprise-IT/` — Enterprise IT, HR & Legal Operations
- `Domain-08-Education/` — Education
